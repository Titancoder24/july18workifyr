Workfyr OS features a powerful Omni Search palette that can be accessed from anywhere within the application.

## Using Omni Search
1. Press `Cmd + K` (Mac) or `Ctrl + K` (Windows) to open the Omni Search palette.
2. Start typing to search across the entire database.

## Supported Entities
Omni Search currently indexes and searches across the following entities:
- **Contacts & Leads**: Search by name or email.
- **Companies**: Search by company name.
- **Deals**: Search by deal value or stage.
- **Employees**: Jump straight to an employee's profile by typing their name.
- **Navigation**: Type keywords like "payroll" or "settings" to quickly navigate to those routes without clicking through the sidebar.
